# MapBiomas rasters (not versioned)

`2000.tif` and `2010.tif` (MapBiomas Collection 9 land cover, Federal District window) are created by
[`download_mapbiomas.R`](download_mapbiomas.R); run it from the repository root. The rasters are only needed
for the three urbanization targets of the pipeline; see [`../../README.md`](../../README.md).
